📌 Key Distribution Paths:

✓ Immediate (GitHub Only)
Anyone can install immediately after you push to GitHub:
claude plugin install https://github.com/your-username/blackduck-ci-plugin

✓ Marketplace (Optional, Requires Approval)
Submit to platform.claude.com/plugins/submit for Anthropic review. Once approved, your plugin appears searchable in Claude Code's plugin marketplace, and updates automatically when you push commits to GitHub.

⚡ Continuous Updates:
Whether users installed from GitHub or Marketplace, they always get your latest commits. Updates happen automatically—no need to re-release.
